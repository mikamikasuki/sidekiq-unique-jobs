# Plans

This repository has no `docs/plans/` directory and no plans checked in. Plans
live in **GitHub issues** on `zoolutions/sidekiq-unique-jobs`.

- `/lode:plan` with no `--file` opens (or updates) an issue.
- `/lode:plan --file` writes here, as `lode/plans/<slug>.md`, for a plan too
  long or too iterative for an issue. Delete it once the work has merged — the
  lode describes the system as it is, and a merged plan is history.
- Session handovers and gate reports go to `lode/tmp/`, which is git-ignored.

`docs/` is the published documentation site, not a place for plans.
